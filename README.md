# Portfólio · Samuel Freitas

Site estático (HTML, CSS e JS puros), pronto para GitHub Pages.

## Estrutura
```
index.html                 página única (fica na raiz para o GitHub Pages achar)
CSS/style.css              estilos e paleta (variáveis no topo do arquivo)
CSS/boxicons/              ícones embutidos (não dependem de CDN)
JS/script.js               menu mobile, filtro de projetos, animações
IMGS/                      foto, logo, favicon
IMGS/projetos/             miniaturas dos projetos
Arquivos/Curriculo/        PDF do currículo (botão "Baixar currículo")
```

## Painéis
As imagens em `IMGS/paineis/` são prints reais com textos, números e logos pixelados.
Para adicionar um painel novo, salve a imagem já ofuscada nessa pasta e inclua um item na galeria do `index.html`.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `FreitaslrS.github.io`
2. Envie o conteúdo desta pasta para a raiz do repositório
3. Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`
4. Em 1–2 minutos o site fica em `https://freitaslrs.github.io`
